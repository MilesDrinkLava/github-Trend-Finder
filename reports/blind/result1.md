# 盲评批次 1 结果

## Q01 能批量重命名文件的工具
- X：相关 6/10，愿意点开 3 条，理由：szyszka、nomino 是正经批量重命名工具，SubRenamer 只针对字幕也算沾边，但 nnn、clifm 是文件管理器，Bilibili 字幕转 ASS 直接跑题。
- Y：相关 2/10，愿意点开 2 条，理由：只有 Muse-SAMA/rename_tool、zbaimo/ReName 从名字看对题，其余 china-dictatorship、x86-bare-metal-examples 等是政治/汇编噪音，toolsbox、SnapForge 这类泛名仓库无从判断。
- Z：相关 9/10，愿意点开 6 条，理由：f2、rnr、renamer、RenameIt、vimv、mnamer 全部对口，star 分布合理，是本批最干净的一份榜单。

## Q02 支持中文的命令行下载器
- X：相关 6/10，愿意点开 4 条，理由：axel、lux、downloader-cli 是对口的命令行下载器，Douyin_TikTok_Download_API 中文站点能力强但偏 API 服务，httpie 是 HTTP 客户端、fast-cli 是测速，均非下载器。
- Y：相关 1/10，愿意点开 1 条，理由：仅 N_m3u8DL-CLI 对口，其余 funNLP、Some-Many-Books 和大量 china-dictatorship 变体全是噪音，整份榜单几乎不可用。
- Z：相关 8/10，愿意点开 5 条，理由：yt-dlp、aria2、lux、N_m3u8DL-CLI、google-images-download 都是可用命令行下载器，仅 ipatool、dio、httpie 三个跑题。

## Q03 本地跑的向量数据库
- X：相关 7/10，愿意点开 4 条，理由：zvec、hyperDB、vectra、vector-storage 从名字到 star 都像本地向量库/向量存储，taladb 可作备选，但 qdrant-mcp-server 只是 MCP 包装、documents-vector-search 太窄。
- Y：相关 4/10，愿意点开 3 条，理由：LEANN、zvec、anything-llm 沾边，但 SeaGOAT、Chat2DB、Resume-Matcher 分别是代码搜索、SQL 客户端、简历工具，Graphify 这个 141.5k star 的陌生项目不敢算数。
- Z：相关 0/10，愿意点开 0 条，理由：整份都是 china-dictatorship 系列政治仓库和无关小仓库，与向量数据库毫无关系，纯噪音。

## Q04 桌面上好看的 markdown 笔记软件
- X：相关 0/10，愿意点开 0 条，理由：榜单为空，无候选。
- Y：相关 8/10，愿意点开 6 条，理由：joplin、fsnotes、notable、marktext、MarkFlowy 是桌面 markdown 笔记/编辑器的代表作，massCode 偏代码片段算半个，末尾 lencx/ChatGPT 完全跑题。
- Z：相关 5/10，愿意点开 2 条，理由：liandi（Leanote 桌面端）、PaperTodo 还算对题，其余是待办小工具或 one-note 转换脚本，没有能一眼认出的 markdown 笔记软件。

## Q05 把视频转成 gif 的工具
- X：相关 5/10，愿意点开 3 条，理由：Gifski、gifify 直接对口，ScreenToGif 是录屏转 gif 的近似需求，但 GSYVideoPlayer、AndroidCamera、Waifu2x、ccapture 全是视频播放/摄像头/放大，噪音占一半。
- Y：相关 9/10，愿意点开 7 条，理由：Gifski、gifify、NSGIF、CuteGIF、Regift、VideoToGIF、core-video-to-gif 条条对口，只有 video2ppt 跑偏，几乎整份可点。
- Z：相关 0/10，愿意点开 0 条，理由：榜单为空，无候选。

## Q06 自己搭的密码管理器
- X：相关 1/10，愿意点开 0 条，理由：NumberOne-MM 名字看不出与密码管理有关，其余全是 china-dictatorship 系列和 PCL2（Minecraft 启动器）等噪音，没有一条能判断对口。
- Y：相关 9/10，愿意点开 7 条，理由：aliasvault、vaultwarden-docker-compose、lesspass、TeamPass、passwordcockpit、vaultage 是自建密码管理器的正统答案，Password-Manager、zero_password_manager 也沾边，仅 awesome-privacy-tools 是清单。
- Z：相关 7/10，愿意点开 5 条，理由：nodewarden（Bitwarden 兼容服务端）、TeamPass、lesspass、Password-Manager 对口，shaark 是书签+笔记偏题，lifeforge、personal-management-system 只是含密码模块的综合自建套件。

## Q07 局域网传文件的小工具
- X：相关 4/10，愿意点开 3 条，理由：matan-h/Transfer、Airshare 是局域网传文件工具，termscp 是 SCP/SFTP 客户端勉强算，open-saas、HRConvert2 完全跑题，SparkleShare 是同步盘。
- Y：相关 3/10，愿意点开 2 条，理由：JamTools 和 LAN-Sharing-Service 算对口，但夹杂大量 china-dictatorship 噪音及 star 0–3 的陌生小仓库，整体质量差。
- Z：相关 9/10，愿意点开 6 条，理由：LAN-Share、LanXchange、dukto、termchat、zerotier/toss 都是局域网传文件的对口/老牌项目，WifiTransfer 也在题，仅末尾学生作业项目偏弱。

---

**本批总结**：Z 总体最强，Q01、Q02、Q07 三度第一，Q06 也接近最佳；Y 在 Q04、Q05、Q06 明显领先，但混入政治垃圾仓的 Q02、Q07 几乎不可用；X 最稳却从未拿第一，Q02/Q03 尚可。未出现「三份都很差」的查询，最弱的是 Q03：Z 全为噪音、Y 大杂烩，仅 X 达到及格线。
