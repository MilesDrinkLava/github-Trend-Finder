# 盲评批次 3

下面是若干条中文搜索意图，每条给出三份候选榜单（X/Y/Z）。
三份榜单来自不同来源，顺序已打乱，你不知道哪份是谁的——这是故意的。

评分规则：
1. 只看「这份榜单能不能让我找到想要的东西」
2. 只给了仓库名和 star，按名字、star 和你自己的了解判断；判断不了就按 0 算
3. 「愿意点开」= 看完仓库名你会真的点进去看 README
4. 每项必须填数字，理由一句话
5. 三份榜单的条数可能不同，条数少不是缺点——只看质量
