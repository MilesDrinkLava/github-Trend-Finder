## 结论

- **A（GitHub 原生中文）基本不可用**：平均 1.30/10，19 条查询输给本系统。大量结果被 `china-dictatorship` 等无关仓库刷屏。
- **B（英文关键词）反超 C（本系统）**：相关性 7.20 vs 6.40，胜场 11 vs 8。结论是「翻译层有价值，排序层目前是负收益」。
- **C 的优势场景**：查询本身带中文特有概念时（markdown 笔记、OCR、代码补全、命令行下载器），扩展层能拉出 B 搜不到的东西。
- **C 的劣势场景**：泛关键词查询（gif、pdf、向量库）。软 AND 放进来一批「沾边但不对口」的仓库——视频播放器支持导出 GIF、PDF 库的 topics 里有 html。

## 方法学提醒

评审只能看到仓库名和 star，因此**对知名项目有天然偏袒**。B 列来自 GitHub 原生排序，天然是高分知名项目；C 列会推出冷门但正确的项目，评审不认识就按 0 分算。所以 B 的实际领先幅度可能小于表上的 0.8 分。
反过来，C 列里被点名的噪音仓库是真实存在的，这部分结论不受此偏差影响。
